## Proyectos destacados

### Aphidex

Aplicación móvil companion para jugadores de **Grounded** y **Grounded 2**.

Incluye información de criaturas, debilidades, resistencias, ataques, variantes, favoritos, tarjetas doradas y soporte multiidioma.

- Publicada en Android
- Publicada en iOS
- Desarrollada con Flutter
- Monetización con AdMob e IAP
- Soporte en español, inglés y ruso

Repositorio relacionado:  
https://github.com/ByteShark-dev/Aphidex-Data

---

### ByteShark Business Manager

Demo tipo CRM / ERP para negocios pequeños.

Incluye módulos simulados de clientes, ventas, citas, cobranza, reportes y configuración. Diseñada como demostración comercial para mostrar cómo un negocio puede centralizar su operación en una plataforma personalizada.

Tecnologías usadas:

- React
- Vite
- CSS modular
- Datos simulados
- Diseño responsive
